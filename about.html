ABOUT GOBUS

Travel made simple.

GoBus is a student-built bus travel website prototype focused on simple route discovery and booking.

Our idea

We designed GoBus to make it easy for travellers to discover bus routes, compare timings and select a seat through a clean interface.

Technology

This prototype uses HTML for the page structure, CSS for the design, JavaScript for simple interactions and JSON for sample bus data.
